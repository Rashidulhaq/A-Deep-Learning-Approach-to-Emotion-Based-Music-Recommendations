## 📌 Overview

Music is closely connected with human emotions. Different emotional states can influence the type of music people prefer at a particular moment.

This project, **"A Deep Learning Approach to Emotion-Based Music Recommendations"**, explores the use of Deep Learning techniques to develop an emotion-aware music recommendation approach.

The project was developed as part of my academic research/thesis and includes the experimental **Google Colab code** along with the **thesis paper**.

---

## 🎯 Objectives

The main objectives of this project are:

* 🧠 Explore the application of **Deep Learning** in emotion-aware systems
* 🎭 Analyze emotional information for music recommendation
* 🎵 Investigate the relationship between **emotion and music preference**
* 🤖 Explore AI-based approaches for personalized recommendations
* 📊 Perform experimentation and analysis using Deep Learning techniques
* 🔬 Document the methodology and findings as an academic research project
